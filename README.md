# EchoVault

Premium monochrome product launch site for EchoVault, a wearable personal AI assistant.

## Run in VS Code

1. Open this folder in VS Code.
2. Open the integrated terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Build

Run `npm run build` to create a production build in `dist/`.

The pendant render and charts are implemented in CSS/SVG, so no external image assets are required.
